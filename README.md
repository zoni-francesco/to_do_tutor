`to_do_tutor` è un piccolo strumento CLI per gestire una piccola agenda di
compiti e progetti da svolgere che mira ad essere efficace, efficente e di
semplice utilizzo.

La soluzione svolge le seguenti operazioni:
- Creazione task
- Visualizzazione dettagliata di una task
- Ricerca anche filtrabile per alcuni parametri
- Contrassegnazione completamento task

Per utilizzare il programma sulla propria macchina prima si apre una finestra
del terminale, poi (in qualsiasi posizione del vostro filesystem) eseguite i
seguenti comandi:
```bash
git clone https://github.com/zoni-francesco/to_do_tutor.git
cd to_do_tutor/
make
./to_do_tutor
```
